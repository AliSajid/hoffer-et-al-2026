# Supplementary data and scripts for Hoffer et al

[![DOI](https://zenodo.org/badge/1425808823.svg)](https://doi.org/10.5281/zenodo.23478545)

This repository contains the scripts and the intermediate data associated with
the paper _Discrepancies in tyrosine kinase signaling between head and neck
cancer cell lines and primary samples_ submitted to [Precision Pathology](https://www.sciencedirect.com/journal/precision-pathology)
